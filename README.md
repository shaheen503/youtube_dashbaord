# YouTube Creator Analytics Dashboard

A data-analytics project focused on summarizing YouTube channel performance and engagement metrics in a dashboard.

## Project Overview
The dashboard is designed to help explore video performance using metrics such as views, likes, comments, and engagement.

## Tools
- Excel
- Power BI

## Analysis Focus
- Compare video performance
- Review engagement indicators
- Summarize channel metrics in visual reports
- Support data-driven content insights
